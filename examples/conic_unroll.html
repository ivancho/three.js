Drag to rotate the camera · right-click drag to pan · scroll to zoom.

The sliced cone and unrolled pattern share one view. Use Move / Rotate below the view to edit the cone (clipping planes follow). T toggles Move, R toggles Rotate. Click the same icon again or Esc to exit. The Level button levels the cut planes.

Paint (B) lets you brush colors onto the flattened pattern; the same UV paint map shows on the cone. Pick a color next to the brush; set opacity, size, and softness in the Paint folder (lower opacity makes the wall see-through), hold Shift to erase. Esc exits Paint. Each stroke is saved (brush settings included) and can be undone with ⌘Z / Ctrl+Z one stroke at a time; strokes persist with autosave / named saves via IndexedDB.

Autosave writes pending edits to local storage immediately (mesh buffers go to IndexedDB; snapshots keep only mesh keys) and promotes up to 20 versions about once a minute. ⌘Z / Ctrl+Z steps back through pending snapshots (then the latest autosave); ⌘⇧Z / Ctrl+Shift+Z steps forward. Peeled redo tails are kept in IndexedDB so undoing a branch-point edit can restore them. Save with a name to store a separate named history. Select a name and version to restore.
